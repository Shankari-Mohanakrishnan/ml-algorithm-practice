# Linear Regression Projects

This folder contains Linear Regression projects implemented using Python, Pandas, Matplotlib, and Scikit-learn.

The notebooks demonstrate:
- regression modeling
- model training
- prediction
- regression assumptions
- residual analysis
- evaluation metrics
- data visualization

---

# Projects Included

## 1. Simple Linear Regression - Home Price Prediction

### Objective
Predict house prices based on house area using Simple Linear Regression.

### Concepts Demonstrated
- Scatter plot visualization
- Independent and dependent variables
- Linear Regression model fitting
- Slope and intercept interpretation
- House price prediction
- Regression equation

### Files
- `SimpleLinearRegression_Homeprice.ipynb`
- `homeprices.csv`

---

## 2. Linear Regression Assumptions and Residual Analysis

### Objective
Demonstrate Linear Regression assumptions and evaluate model performance using residual analysis.

### Concepts Demonstrated
- Train-test split
- Model training and prediction
- Residual error analysis
- Regression assumptions
- Error visualization
- Mean Squared Error (MSE)
- R² Score

### Assumptions Covered
- Linearity
- Independence
- Homoscedasticity
- Normality of residuals
- No multicollinearity

### Files
- `Linear_Regression_Assumptions_and_Residual_Analysis.ipynb`
- `sales.txt`
