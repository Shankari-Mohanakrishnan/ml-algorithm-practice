# Decision Tree Projects

This folder contains Decision Tree machine learning classification projects implemented using Python and Scikit-learn.

The notebooks demonstrate:
- decision tree classification
- entropy and gini impurity
- feature splitting
- categorical encoding
- model training and prediction
- decision boundaries
- model evaluation
