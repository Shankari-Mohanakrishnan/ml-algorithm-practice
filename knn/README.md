# K-Nearest Neighbors (KNN) Projects

This folder contains K-Nearest Neighbors machine learning projects implemented using Python and Scikit-learn.

The notebooks demonstrate:
- distance-based learning
- KNN classification
- KNN regression
- feature scaling importance
- train-test split
- model prediction
- evaluation metrics

---

# Projects Included

## 1. KNN Classification

### Objective
Build a KNN classification model to predict categorical outcomes.

### Concepts Demonstrated
- KNN classification workflow
- distance-based prediction
- choosing number of neighbors
- train-test split
- classification accuracy
- model evaluation

### File
- `knn_classification.ipynb`

---

## 2. KNN Regression

### Objective
Build a KNN regression model to predict continuous numerical values.

### Concepts Demonstrated
- KNN regression workflow
- distance-based prediction
- train-test split
- regression evaluation
- prediction using nearest neighbors

### File
