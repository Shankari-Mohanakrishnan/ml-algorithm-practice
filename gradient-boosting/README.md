# Gradient Boosting Projects

This folder contains Gradient Boosting machine learning projects implemented using Python and Scikit-learn.

The notebooks demonstrate:
- boosting algorithms
- sequential tree learning
- regression and classification workflows
- model evaluation
- hyperparameter tuning
- ensemble learning concepts
